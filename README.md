# 台股個股初步分析 Skill（tw-stock-initial-analysis）

一套給 [Claude](https://claude.ai) 使用的六步驟台股分析框架，核心原則是「現金流優先、基本面在後」——先用現金流量表做「盲測」，避免公司背景、產業地位、法說會樂觀話術等資訊，讓分析帶著先入為主的印象。

> ⚠️ **這是一套分析方法論，不是投資建議。** 本 Skill 產出的任何評分、估值、觀察訊號，僅為輔助思考的工具，不構成買賣邀約。投資有風險，請自行判斷並承擔後果。

## 這套 Skill 在做什麼

分析流程共六步，前一步的結論會影響是否要繼續下一步：

1. **現金流量表六大規則分析**（盲測階段，最優先）——只看現金流數字本身，不查股價、EPS、產業地位，避免先入為主
2. **基本資訊查詢**——股價、EPS、殖利率、營收、法說會連結，皆附實際查詢連結
3. **法說會資料深入討論**——依公司實際內容彈性決定深挖方向，不套用固定題材模板
4. **營收趨勢視覺化**——近 8-12 期月營收直條圖
5. **前瞻本益比／EPS 預估**——同時用隱含本益比與目標本益比法雙重檢視估值
6. **投資決策推理**——僅在使用者主動詢問時才進行，附上具體可驗證的觀察條件

每個步驟的輸出都會累加進同一份 HTML 報告，附頂部導覽選單方便跳轉查閱。

## 這套 Skill 是怎麼來的

不是憑空寫出來的 SOP，而是先認真做過好幾次真實的股票分析（跟 Claude 來回討論、糾正查錯的地方、補漏掉的細節），再把整個過程蒸餾成這份 Skill。所以裡面很多規則背後，都對應到一次真實發生過的判斷失誤或修正——例如「資料來源必須附實際連結」這條規則，就是因為曾經漏寫連結被抓包才加進去的。

## 如何使用

1. 到 [claude.ai](https://claude.ai) 的 Projects 功能中，將 `SKILL.md` 上傳為專案的 Skill／知識檔案（或依 Claude 當前支援的 Skill 上傳方式操作，介面可能持續更新，請以官方文件為準）
2. 開新對話，提供股票代號或公司名稱，並附上現金流量表資料（截圖或原始數字）即可開始分析
3. 若沒有現成資料，Skill 會主動附上對應個股的 Goodinfo 查詢連結，方便您截圖上傳

## ⚙️ 使用前必須修改的地方

這份 Skill 原本包含我個人的 GitHub 版控設定，**如果你要使用，必須先替換成你自己的 repo**，否則 AI 會嘗試把分析報告 push 到別人（我）的 repository：

在 `SKILL.md` 中搜尋以下內容並替換：

| 原始內容 | 替換為 |
|---|---|
| `https://github.com/mjib007/stock-analysis` | 你自己的 repo 網址 |
| `http://mjib007.github.io/stock-analysis/{檔名}` | 你自己的 GitHub Pages 網址格式 |

若你不需要 Git 版控功能（例如只想在對話中看報告，不需要存到 GitHub），可以直接刪除 SKILL.md 中「Git 版控與發布規則」整個章節。

## 已知限制

- 股價、EPS、營收等數字依賴網路搜尋與第三方網站，同一時間點不同來源偶爾會出現數字不一致的情況；Skill 設計上會如實並陳、不擅自判斷對錯，但使用者仍應自行以官方公告（公開資訊觀測站 MOPS）或看盤軟體核實
- 部分網站（如 MOPS 簡報 PDF）因 robots.txt 限制無法直接讀取內容，只能附上連結供使用者自行查閱
- 使用者截圖提供的原始資料，通常比 AI 自行搜尋取得的資料更可靠，建議關鍵數字（現金流量表、月營收、月K棒）優先用截圖方式提供
